# VideoGuru — Agent Instructions

## Application Building Context

Read the following files in order before implementing or making any architectural decision:

1. `context/project-overview.md` — product definition, goals, features, and scope
2. `context/project_overview.md` — full architectural framework document (reference source)
3. `context/spec_file.md` — complete spec breakdown of all development steps
4. `context/progress-tracker.md` — current phase, completed work, open questions, and next steps


On the completion of each spec in the file `context/spec_file.md`, you are required to update the `context/progress-tracker.md` file with the status of the completed spec. Mark spec as complete if the spec is implemented and unit tested.  Do not mark spec as complete if it is not implemented and unit tested.
